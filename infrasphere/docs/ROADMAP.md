# Roadmap

## MVP

Login, organizations, cloud account registration, mock provider, AWS starter adapter, inventory dashboard, resource detail, deployment wizard, AI assistant UI, observability abstraction, cost dashboard, security findings, Docker Compose, and docs.

## Enterprise Version

Persistent repositories, real cloud SDK integrations, OIDC/SAML, encrypted credentials, approvals, audit retention, policy engine, advanced RBAC, multi-region deployment, and enterprise supportability.

## AI-Native Version

RAG over inventory, topology-aware reasoning, incident triage, FinOps advisor, Terraform and Kubernetes plan explanation, approval-backed AI actions, and postmortem generation.

## Marketplace Ecosystem

Plugin model for providers, observability backends, cost engines, policy packs, remediation workflows, and internal platform extensions.

## Policy Engine

OPA/Rego or Cedar-backed policy checks for deployments, regions, tags, exposure, IAM, encryption, and production change controls.

## FinOps Automation

Idle detection, rightsizing, anomaly detection, budget alerts, savings plan recommendations, and approved remediation workflows.

## Security Posture Management

Cloud security findings, compliance mapping, network exposure, IAM risk, encryption gaps, old Kubernetes versions, backup gaps, and IaC remediation.

## Sovereign Cloud Support

Support isolated regions, private cloud, edge, air-gapped deployments, customer-managed keys, and strict data residency.
